# صور التمارين

## الرجال (male) — صور حقيقية لكل نظام تمرين
دلوقتي عندك 3 أنظمة تمرين للرجال، وكل نظام له مجلد صور حقيقية منفصل:

    photos/male/iron/<slug>.jpg     ← نظام Iron Split (الافتراضي، 5 أيام)
    photos/male/ppl/<slug>.jpg      ← نظام Push / Pull / Legs
    photos/male/arnold/<slug>.jpg   ← نظام Arnold Split

الـ `<slug>` هو اسم التمرين بحروف صغيرة وشرطات بدل المسافات، زي:
`barbell-bench-press.jpg`, `lat-pulldowns.jpg`, `hip-thrusts.jpg` … إلخ.
التطبيق بيحدد المجلد تلقائيًا حسب النظام اللي المستخدم اختاره في صفحة "حسابي".

لو حابب تستبدل أو تضيف صورة تمرين معين، خليها بنفس اسم الملف (الـ slug) جوه
مجلد النظام المناسب، ولو الصورة مش موجودة هيرجع التطبيق تلقائيًا للرسمة
التوضيحية Offline من غير أي تعديل في الكود.

## البنات (female)
لسه مفيش صور حقيقية مضافة للبرنامج النسائي؛ التطبيق بيعرض الرسومات التوضيحية
Offline (جوه images/female) لحد ما تتضاف صور حقيقية بنفس الطريقة:

    photos/female/<key>.jpg

⚠️ تأكد إن أي صورة بتضيفها مرخصة للاستخدام (ملكك، أو من مصدر Royalty-Free
زي Pexels/Unsplash بترخيص يسمح بالتوزيع جوه تطبيق)، عشان تتجنب مشاكل حقوق الملكية.
