# Photo credits

Exercise photos are bundled from Wikimedia Commons and downloaded during the
GitHub Actions build (`.github/workflows/build-apk.yml`). Each source retains
its original license; see the linked file page for attribution/license
details. The workflow verifies every download is a real image (not a broken
link/HTML error page) and fails the build instead of shipping a blank image
if a source ever moves.

## Honest substitution note

- **Hip thrust**: Commons has no dedicated hip-thrust-machine photograph. A
  barbell glute bridge — the same hip-extension movement pattern, performed
  with the same setup a hip thrust uses — is shown instead
  (https://commons.wikimedia.org/wiki/File:Bridge_(exercise)_-_USDAgov.jpg).
  This is a real photo of a closely related exercise, not a mismatched photo
  of unrelated equipment (an earlier build mistakenly reused a leg-press
  photo for this slot — fixed in 2.1.1).
- **Adductor machine**: the closest labelled Commons photo is of a hip
  abductor/adductor combo machine; if you have access to a dedicated
  adductor-only photo with a compatible license, swap it in.
