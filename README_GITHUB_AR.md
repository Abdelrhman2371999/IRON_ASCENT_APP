# IRON ASCENT v1.0.2

نسخة Android Offline من IRON ASCENT.

## الجديد
- صفحة مستقلة لنظام الأكل.
- مواعيد الوجبات قابلة للتعديل.
- تذكيرات يومية حقيقية على Android حتى مع إغلاق التطبيق.
- زر لتفعيل كل التذكيرات أو إيقافها.
- صور محلية لكل Split: السبت، الأحد، الاثنين، الأربعاء، الخميس.
- فتح البرنامج تلقائيًا على تمرين اليوم.
- الثلاثاء والجمعة أيام راحة.
- حفظ الوزن والـcheckmarks محليًا.
